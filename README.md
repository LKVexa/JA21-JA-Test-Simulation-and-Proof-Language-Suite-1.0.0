# JA21-JA-Test-Simulation-and-Proof-Language-Suite-1.0.0

Discover verification language design with 10,000 technical records, 1,000 JATP programs, and a 22-chapter textbook. Study fixtures, properties, deterministic simulation, and proof obligations via specifications, catalogs, lessons, and offline tools. Updated examples separate fixture oracles from bounded invariants for clearer, documented research.

The JA Test, Simulation, and Proof Language Suite provides research and teaching material for verification engineering. It contains 10,000 source-linked technical records and 1,000 curated JAP programs, organized across ten proficiency levels, ten validation classes, and 32 labeled verification features. Fixtures, properties, deterministic simulation concepts, and proof obligations give readers a structured way to examine the relationship between a claim, its test inputs, and its expected evidence.

A 22-chapter textbook, curriculum, workbook, and instructor guide support progressive study. Specifications, compiler and runtime contracts, feature and script catalogs, conformance material, offline tools, and preserved sources connect individual examples to the proposed architecture. The updated release separates literal fixture inputs and expected results from bounded nondecrease properties in expected-pass examples, while retaining the deliberate failure sources and documenting the associated changes.

The suite serves verification educators, language researchers, and designers evaluating proof contracts. Independent fixture oracles and corrected declarations improve the reference material. Native parsing, simulation, proof checking, model checking, coverage collection, and executed arithmetic semantics remain implementation work, with historical coupling annotations separately qualified.

## Corpora and audit records
