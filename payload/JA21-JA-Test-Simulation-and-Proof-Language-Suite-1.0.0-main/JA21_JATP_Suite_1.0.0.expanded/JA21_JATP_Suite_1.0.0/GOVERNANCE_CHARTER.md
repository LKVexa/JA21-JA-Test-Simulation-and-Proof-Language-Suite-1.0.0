# Governance Charter

## Purpose

Govern this suite as a language, evidence, education, and conformance product for JA21 verification engineering.

## Decision lenses

SOPHIA reviews semantic coherence; CHARLOTTE reviews information architecture and diagnostics; LANDON reviews implementation feasibility; Professor reviews invariants, counterexamples, proofs, and pedagogy; Podium reviews publication and certification readiness.

## Non-negotiable controls

- Deterministic seeds, clocks, event order, and failure schedules.
- No hidden network or unknown-code authority.
- Counterexamples and original failure witnesses are preserved.
- Proof identity and obligations cannot be removed by optimization.
- Resource and benchmark conditions are explicit.
- Coverage names the measured layer.
- No native-execution or certification claim without reproducible evidence.
