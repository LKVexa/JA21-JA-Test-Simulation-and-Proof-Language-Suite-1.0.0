# Publication System — Verification Orrery

The suite uses an air-gap-safe institutional visual system designed for dense technical material.

- **Obsidian** identifies authoritative source and runtime surfaces.
- **Cyan** identifies tests, events, and observable execution paths.
- **Violet** identifies proofs, temporal relations, and R12/MCRT provenance.
- **Amber** identifies certification, stable hashes, and release gates.
- **Red** is reserved for rejected claims, counterexamples, and unresolved evidence.

Documents use short paths, numbered learning tracks, compact evidence cards, local SVG artwork, source-to-receipt navigation, monochrome-safe tables, and no remote fonts, scripts, styles, telemetry, or network assets.
