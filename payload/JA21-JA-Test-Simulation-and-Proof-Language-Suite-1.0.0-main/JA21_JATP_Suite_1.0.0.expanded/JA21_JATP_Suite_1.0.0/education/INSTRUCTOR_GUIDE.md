# Instructor Guide

Teach verification as a language of claims, controlled environments, reproducible counterexamples, checkable proofs, and evidence-bearing receipts. Grade explicit oracles, seeds, virtual clocks, fault schedules, proof dependencies, resource limits, coverage layers, replay, and evidence boundaries—not merely whether a script says `pass`.

## Five-role review

- SOPHIA: semantic and systemic coherence
- CHARLOTTE: legible verification architecture and diagnostics
- LANDON: compiler, simulator, proof checker, runtime, sandbox, and replay feasibility
- Professor: invariants, counterexamples, proofs, and tests
- Podium: publication, integrity, limitations, and certification

## Rubric

| Dimension | Weight |
|---|---:|
| Source and language correctness | 20% |
| Test/simulation/proof semantics | 20% |
| Determinism, resources, and recovery | 20% |
| Evidence identity, replay, and coverage | 20% |
| Diagnostics, limitations, and publication | 20% |
