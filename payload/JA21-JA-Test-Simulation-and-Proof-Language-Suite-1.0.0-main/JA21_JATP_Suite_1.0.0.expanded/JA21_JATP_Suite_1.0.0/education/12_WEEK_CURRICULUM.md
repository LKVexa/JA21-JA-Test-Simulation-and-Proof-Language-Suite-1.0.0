# JA21 JA Test, Simulation, and Proof Language — Twelve-Week Curriculum

| Week | Theme | Chapters | Laboratory evidence |
|---:|---|---|---|
| 1 | Suite identity, modules, and execution policy | 1–2 | Minimal verification suite and evidence map |
| 2 | Fixtures, generators, assertions, and matchers | 3–4 | Reproducible inputs and typed oracle |
| 3 | Unit, parameterized, integration, and behavior tests | 5 | Layered test portfolio |
| 4 | Scenarios, events, UI, and agent simulation | 6–7 | Virtual timeline and environment trace |
| 5 | Network/distributed failure simulation | 8 | Fault schedule and recovery evidence |
| 6 | Property tests, fuzzing, shrinking, counterexamples | 9–10 | Generated domain and minimal witness |
| 7 | Invariants, theorems, lemmas, and obligations | 11–12 | Formal claim and dependency graph |
| 8 | Proof terms and temporal properties | 13–14 | Checkable proof and counterexample trace |
| 9 | Resources, benchmarks, and coverage | 15–16 | Bounded performance and four-layer coverage |
| 10 | Typed AST, compiler diagnostics, and negative cases | 17–18 | Typed verification IR and diagnostic suite |
| 11 | Runtime replay, optimization, R12, and MCRT | 19–21 | Equivalence and evidence packet |
| 12 | Standalone toolchain capstone | 22 | Auditable offline verification release |

## Assessment

- Laboratories: 40%
- Negative/determinism/recovery portfolio: 20%
- Mid-course architecture review: 15%
- Capstone suite and evidence packet: 25%
