# Certification Guide

## Levels

1. **Corpus integrity** — counts, hashes, schemas, indexes, and source preservation.
2. **Language structure** — parser, resolver, types, effects, capabilities, and diagnostics.
3. **Verification semantics** — tests, simulation, proofs, counterexamples, coverage, and benchmarks.
4. **Runtime replay** — sandbox, virtual time, seeds, faults, resources, recovery, and identical receipts.
5. **Publication certification** — signed artifacts, limitations, tool identities, and independent audit.

No certification level may claim native results when only modeled corpus evidence is available.
