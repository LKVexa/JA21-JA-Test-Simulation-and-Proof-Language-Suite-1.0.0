# Role-Based Reading Paths

## Test author
Read Chapters 1–11, then work through positive, boundary, and integration scripts in the first three learning tracks.

## Simulation engineer
Read Chapters 6–10, 15, and 19–22. Focus on virtual time, ordered events, failure injection, resource bounds, deterministic replay, and recovery.

## Formal-methods engineer
Read Chapters 11–14 and 17–22. Focus on invariants, model assertions, theorems, proof obligations, proof terms, temporal properties, and evidence lowering.

## Compiler and runtime engineer
Read Chapters 2, 15–22. Use negative and determinism records to specify diagnostics, typed ASTs, R12 plans, schedulers, proof checking, coverage, benchmark isolation, and receipts.

## Instructor and certifier
Use the textbook, curriculum, workbook, certification guide, and all ten validation classes. Require explicit separation of modeled, structural, native, and certified evidence.
